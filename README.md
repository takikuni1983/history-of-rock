# ロックの系譜 — Tree of Rock

ロック音楽のジャンルの**系譜（けいふ）**を、生物の進化のように辿るインタラクティブ Web アプリです。
ブルースという源流から、ロックンロール・サイケ・ハードロック・メタル・パンク・オルタナ…へと
枝分かれしていく様子を、フローチャート／系統樹に似た有機的な UI で表現しています。

## 特徴

- **系統樹ビジュアル** — 時代を上（1940s ルーツ）から下（2000s〜）へ流し、
  親ジャンル → 派生ジャンルを発光する曲線でつなぎます。ノードは「細胞／生命」のように
  ゆっくり呼吸（明滅）します。
- **系譜ハイライト** — ジャンルにカーソルを合わせると、その**祖先と子孫の系統だけ**が光り、
  無関係な枝は沈みます。どこから来て、どこへ進化したのかが一目で分かります。
- **ジャンル詳細（フロートウインドウ）** — ジャンルをタップすると浮かび上がる窓に、
  - 系譜のつながり（親／子ジャンルへジャンプ可能）
  - **ジャンルの解釈（諸説あり）** — 定義が割れる論点も含めて解説
  - 音楽的特徴・様式
  - 象徴的なビジュアル・美学
  - 盛んだった年代
  - 代表アーティスト（各2〜3組）と象徴曲の**その場試聴**
- **年代の時代背景** — 左端の年代ラベルをタップすると、その時代の
  文化・世界情勢（公民権運動、ベトナム戦争、オイルショック、冷戦終結など）と
  音楽の関わりを解説します。
- **有機的で情緒的な演出** — 原始の海を思わせる背景、漂う胞子、枝が「成長」する
  アニメーション、なめらかなパン／ズーム。

## 使い方

追加のビルドやサーバーは不要です。ブラウザで `index.html` を開くだけで動きます。

```
# 例: ローカルサーバーで開く場合
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

- **ドラッグ**で移動、**ホイール／ピンチ**で拡大縮小、右下のボタンでも操作できます。
- **⤢** ボタンで全体表示（ルーツ）に戻ります。

## 試聴について（Spotify 埋め込み）

各曲はタップするとその場に **Spotify のプレーヤー**を埋め込み、再生します
（曲ごとに実在のトラック ID を紐付け済み）。Spotify にログインしていない場合は
約 30 秒のプレビュー、ログイン済みならフル尺で再生されます。
著作権の都合で音源そのものは同梱していません。うまく再生されない場合は、
各曲の「Spotify ↗」リンクやプレーヤー下のリンクから Spotify アプリで開けます。

## 構成

```
index.html      … 画面の骨組み
css/styles.css  … デザイン（有機的・情緒的なスタイル）
js/data.js      … ジャンル系譜と年代のコンテンツ（ここを編集すると内容が増やせます）
js/app.js       … 系統樹の描画・操作・フロートウインドウ・試聴
```

### データの拡張

`js/data.js` の `GENRES` に 1 ジャンル 1 オブジェクトを追加するだけで枝が増えます。

```js
{
  id: "shoegaze",          // 一意なID
  name: "シューゲイズ",     // 表示名(日本語)
  en: "Shoegaze",          // 英語表記
  gen: 8,                  // 世代(縦の行)。数字が大きいほど新しい時代
  x: 0.57,                 // 横位置 0.0〜1.0
  years: "1990–1995",
  parents: ["post_punk", "college_alt"], // 親ジャンルのid（複数可＝多系統）
  hue: 290,                // ノード／枝の色相
  tagline: "…",
  interpretation: "…",     // 解釈・諸説
  sound: "…", visual: "…", era: "…",
  artists: [
    { name: "My Bloody Valentine", note: "…",
      // sp = Spotify のトラックID（open.spotify.com/track/<ID> の <ID> 部分）
      songs: [{ t: "Only Shallow", q: "My Bloody Valentine Only Shallow", sp: "52UcjsM15hjCQAUbTW2hy1" }] },
  ],
}
```

## 注記 — 系譜と「解釈」について

音楽ジャンルの系譜は、生物の系統樹のようにきれいな一本道ではありません。
どのジャンルが「親」かは論者によって解釈が分かれ、多くのジャンルは複数の源流を持ちます。
本アプリはその**多系統性**と**解釈の揺れ**をあえて図と文章の両方で示しています。
ここに描いた枝は「唯一の正解」ではなく、ロックの進化を辿るための**一つの地図**です。
